# Warehouse Management Studio (WMS)

Ένα σύγχρονο Πληροφοριακό Σύστημα Διαχείρισης Αποθήκης για Μικρομεσαίες Επιχειρήσεις, υλοποιημένο ως Progressive Web Application (PWA).

## 📖 Σχετικά με το Project
Το Warehouse Management Studio είναι μια υβριδική web εφαρμογή (PWA) με καθαρά απογραφικό σκοπό. Επιτρέπει την παρακολούθηση προϊόντων ανά αποθήκη, την αποτύπωση ποσοτήτων και αξίας, καθώς και την καταγραφή ιστορικού απογραφών. Σχεδιάστηκε με έμφαση στη λειτουργία σε συνθήκες με ασταθή ή ανύπαρκτη σύνδεση στο διαδίκτυο (offline-first).

## ✨ Βασικά Χαρακτηριστικά
- **Offline-First Λειτουργία:** Απρόσκοπτη εργασία χωρίς σύνδεση με τοπική αποθήκευση (IndexedDB) και αυτόματο συγχρονισμό μόλις αποκατασταθεί το δίκτυο.
- **Σάρωση Barcode (Barcode Scanning):** Υποστήριξη εξωτερικών σαρωτών (USB/Bluetooth) και χρήσης της κάμερας της φορητής συσκευής (μέσω Html5Qrcode).
- **Προηγμένη Ταυτοποίηση (Authentication):** Ασφαλής σύνδεση με χρήση JWT (JSON Web Tokens) και Refresh Tokens.
- **Ρόλοι Χρηστών (RBAC):** Διαφορετικά δικαιώματα πρόσβασης για Διαχειριστές (Admins) και Υπαλλήλους (Employees).
- **Dashboard & Στατιστικά:** Γραφικές απεικονίσεις και στατιστικά κινήσεων, κορυφαίων προϊόντων και συνολικής αξίας αποθέματος.
- **Διαχείριση Οντοτήτων (CRUD):** Πλήρης διαχείριση Προϊόντων, Αποθηκών, Χρηστών και Ανακοινώσεων.
- **Εξαγωγή Δεδομένων:** Δυνατότητα εξαγωγής των απογραφών σε αρχείο Excel.

## 🛠️ Τεχνολογίες
Η εφαρμογή ακολουθεί τις αρχές της "Καθαρής Αρχιτεκτονικής" (Clean Architecture) και αξιοποιεί το οικοσύστημα της Microsoft.
- **Frontend:** Blazor WebAssembly, HTML5/CSS, Bootstrap 5, JavaScript Interop.
- **Backend:** C#, .NET, ASP.NET Core Web API.
- **Βάση Δεδομένων:** Microsoft SQL Server, Entity Framework Core (EF Core).
- **Άλλα Εργαλεία:** JWT Bearer Authentication, Html5Qrcode, IndexedDB.

## 📱 Χρήση (PWA)
Η εφαρμογή μπορεί να εγκατασταθεί απευθείας στην επιφάνεια εργασίας ή στην αρχική οθόνη του κινητού σας μέσω του browser, προσφέροντας εμπειρία παρόμοια με native εφαρμογή.
